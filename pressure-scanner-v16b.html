💾 Backup & Restore — protect your data before any change

Your data lives only in this browser's storage. Download a full backup BEFORE clearing storage, switching browsers, migrating to the VPS database, or doing anything that could lose data. The file you download has every analysis entry, every tracked trade, every setting — everything. You can re-import it later to restore.

📡 VPS Sync — pull analytics from your VPS database

Connect this browser to the SQLite database on your VPS so the Analytics page shows your full historical dataset (not capped by browser storage). Local scanning continues either way as a backup; this only affects what the Analytics tab reads.
Setup with SSH tunnel: open PowerShell on your laptop and run
ssh -N -L 3000:localhost:3000 root@YOUR_VPS_IP
Leave that window open while using analytics. The URL above stays http://localhost:3000.
